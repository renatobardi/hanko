### O Hanko passa a enviar a branch do worktree ao repositório remoto (ADR-0091)

- A branch em que a persona trabalha (worktree da task, ADR-0054) agora pode ser enviada ao remoto pelo Hanko, com a credencial do workspace, por ação explícita: botão "Enviar branch" na aba Git da task, `POST /tasks/{task}/git/push`, `hanko task git push <task>` ou, pela persona, a tool `hanko_git_push`, que passa pela política de tools (sem política, pergunta ao gate; `hanko tool-policy set allow --native hanko_git_push --persona <slug>` libera). Alterações soltas viram um commit antes; o envio nunca acontece sozinho no fim da run. Com a branch no remoto, a persona abre o pull request pela integração do repositório. A aba Git e a API mostram o último commit enviado (`pushed_sha`, `pushed_at`; migration 00219). A credencial do workspace precisa de permissão de escrita no repositório para o envio funcionar.

- English summary: the branch the persona works on (the task worktree, ADR-0054) can now be pushed to the remote by Hanko, with the workspace credential, on an explicit action: the "Push branch" button on the task's Git tab, `POST /tasks/{task}/git/push`, `hanko task git push <task>`, or, from the persona, the `hanko_git_push` tool, which goes through the tool policy (without a policy it asks the gate; `hanko tool-policy set allow --native hanko_git_push --persona <slug>` allows it). Loose changes become a commit first; the push never happens on its own at the end of a run. With the branch on the remote, the persona opens the pull request through the repository integration. The Git tab and the API show the last pushed commit (`pushed_sha`, `pushed_at`; migration 00219). The workspace credential needs write permission on the repository for the push to work.
