### Conversa com projeto: o chat e a sala passam a trabalhar no workspace e no ambiente do projeto

- Uma conversa (chat direto ou sala) pode ter um projeto, escolhido ao abri-la: seletor "Projeto (opcional)" na UI, campo `project` (id ou slug) no `POST /conversations` e `hanko chat <persona> "…" --project <slug>`. Com projeto, as runs da conversa usam o workspace e o ambiente dele na mesma precedência das tasks (projeto > persona > diretório temporário); antes o chat só olhava o workspace da persona e, sem ele, rodava num diretório temporário sem ver o repositório. A saída da API traz `project_id`; a página da conversa mostra o projeto. ADR-0090; migration 00218 (`conversations.project_id`, opcional).

- English summary: a conversation (direct chat or room) can now have a project, chosen when it is opened: a "Project (optional)" selector in the UI, a `project` field (id or slug) on `POST /conversations`, and `hanko chat <persona> "…" --project <slug>`. With a project, the conversation's runs use its workspace and environment with the same precedence as tasks (project > persona > temporary directory); before, a chat only looked at the persona's workspace and, without one, ran in a temporary directory without seeing the repository. The API output carries `project_id`; the conversation page shows the project. ADR-0090; migration 00218 (`conversations.project_id`, optional).
