### Readiness confere os segredos do adapter_config e recusa modelo que é só família de preço

- O teste de readiness ganha o passo `secrets`, antes do ambiente: toda referência `${secret:}` do `adapter_config` precisa resolver e toda `${secretfile:}` precisa existir, estar ao alcance da persona (coleções, ADR-0068) e apontar um campo que vira arquivo. Antes, `${secretfile:}` nem era conferido (a run falhava no início) e uma `${secret:}` inexistente aparecia como falha do passo `environment`. O detalhe do passo lista os nomes das referências, nunca valores.
- O passo `model` passa a falhar quando o modelo é o nome de uma família de preço (`claude-haiku`, `claude-sonnet`, `claude-opus`), que o harness não aceita em `--model`; a dica aponta o alias (`haiku`) ou o id completo. O catálogo de modelos deixa de oferecer essas famílias como opção.
- Linhas novas no troubleshooting do RUNBOOK; a lista de passos da API (`secrets,environment,binary,auth,model`) e a UI mostram o passo novo.

- English summary: the readiness probe gains a `secrets` step, run before the environment: every `${secret:}` reference in the adapter_config must resolve, and every `${secretfile:}` must exist, be reachable by the persona (collections, ADR-0068) and point at a field that can become a file. Before, `${secretfile:}` was not checked at all (the run failed at start) and a missing `${secret:}` was reported under the `environment` step. The step detail lists reference names, never values. The `model` step now fails when the model is a price family name (`claude-haiku`, `claude-sonnet`, `claude-opus`), which the harness does not accept in `--model`; the hint points at the alias (`haiku`) or the full model id, and the model catalog no longer offers those families. New troubleshooting rows in the RUNBOOK; the API step list and the UI show the new step.
