# ADR-0007 — Auth v0.1: providers `local` e `firebase`
Data: 2026-10-13 · Status: aceita (revisada por ADR-0014)

## Decisão
Modos: `trusted` (loopback/Tailscale, sem auth) e `authenticated`. Em `authenticated`, provider configurável: `local` (email/senha argon2id, sessão cookie — default self-host) ou `firebase` (ADR-0014). API keys de agente (hash SHA-256). Run JWT curto. Multi-humano v0.2; OIDC v1.

## Consequências
hanko.oute.pro com login Google/email via Firebase. Self-host sem dependência de SaaS por default. Sem RBAC humano no v0.1.
