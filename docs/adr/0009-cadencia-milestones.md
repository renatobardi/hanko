# ADR-0009 — Cadência: milestones curtos, demo gravada, alavancas de velocidade
Data: 2026-10-13 · Status: aceita (revisada no mesmo dia: mais velocidade)

## Decisão
M1–M6 conforme ROADMAP (meta 8 semanas com ≥20 h/sem; base 12). Demo gravada ao fim de cada milestone + checkpoint de demo semanal. Tag `v0.1.0-mN`. Lead-orchestrator + 3 trilhas paralelas de subagentes + crítico cego, sempre depois do contrato (migrations + domínio + OpenAPI). Incremento visível por sessão (AGENTS.md). Dogfood a partir do M2. Estourou 2x → corta escopo, nunca estica. M1 não roda em 1 semana (2 com <20 h) → reavalia o projeto.

## Consequências
Escopo é variável; prazo não. Horas/semana precisam ser confirmadas. Velocidade vem de horas, paralelismo e corte de escopo — não de pular testes em domain/heartbeat.
