# ADR-0002 — Escopo v0.1 = núcleo completo em 6 milestones com gates
Data: 2026-10-13 · Status: aceita

## Contexto
Opções: (A) loop mínimo sem UI; (B) A + UI mínima; (C) núcleo completo (org chart, approvals, budget, routines, UI). Escolha: C. Projetos anteriores do autor morreram por falta de funcionalidade visível.

## Decisão
v0.1 = C, cortado em M1–M6 (docs/ROADMAP.md), cada um com demo gravada e tag. C é destino, não primeiro entregável.

## Consequências
Nada de "pronto quando pronto". Regras de parada do ROADMAP são vinculantes.
