## Como validar no hanko-prd
1. `hanko persona update ada --instructions "texto novo" --reason "teste"`; `hanko persona history ada`; `hanko persona history ada --show 2 --against 1`; `hanko persona restore ada 1`. UI: `/c/<empresa>/personas/ada/instrucoes` (editar, diff, restaurar). Depois de uma execução, a página da run mostra "Instruções rN · sha".
2. Persona propõe: a tool `hanko_persona_instruction_propose` abre um gate em `/c/<empresa>/gates` (tipo instruction, com diff); aprovar cria a revisão (autor persona, ator humano); se alguém editou no meio, aprovar dá conflito.
3. Anexo: arraste um arquivo no cartão "Anexos" da task ou no compositor de comentário; `hanko attach arq.pdf --task HNK-1`; o briefing da próxima run traz "## Anexos" e a persona lê com `hanko_attachment_get`.
4. Rascunho: digite no comentário, abra a task em outro navegador (o texto aparece); enviar limpa. API: `GET/PUT/DELETE /api/v1/companies/{c}/drafts/{task|conversation}/{id}`.
5. Chat: envie `/new` (ou `hanko chat ada "/new" --conversation ID`): aparece "Contexto reiniciado" e a run seguinte não retoma a sessão.
